理解星宿的坐标系统

汉代天文学家为星空建立了精确的坐标系统,将无形的天体转化为可量化的数据。本项目采用以长安(东经109°,北纬35°)为中心的极坐标系统。

星宿坐标要素

距度 (Angular Width)
定义： 各星宿沿赤道方向的角度跨度（单位：度）
作用： 确定星宿的宽度范围
范围： 1°~33°(※井宿最大33°)
计算： 通过连续的星宿位置差计算
累积赤经 (Cumulative Right Ascension)
定义： 从春分点起始，沿赤道向东计测的角度总和
作用： 确定星宿的经度位置
范围： 0°~360°(完整周天)
关系： 累积赤经 = Σ 距度（前序星宿）
方位角 (Azimuth)
定义： 从长安出发指向星宿的地理方向角
参考： 正北为0°,顺时针递增
范围： 0°~360°
计算： 方位角 = 累积赤经 x (360° ÷ 二十八宿周期)

从天球到地图的转换

将二十八宿的天文数据转换为现代地图坐标，融合古代天学与地理学。整个转换过程分为三个核心步骤。

第一步：数据提取与标准化

输入数据来源：
星宿名称：二十八宿名录
距度：各星宿的角宽度
累积赤经：从春分点起的累积角度
分野州郡：对应的地理区域
参考坐标（长安）：
X₀ = 109° (东经)
Y₀ = 35° (北纬)

第二步：方位角计算

核心公式：
方位角 (Azimuth) = 累积赤经 x 360 ÷ 365

数学角度转换：
数学角度 = 90° - 方位角 (度)

弧度转换：
数学角度_弧度 = 数学角度 x (π ÷ 180°)

示例（角宿）：
方位角 = 0° (东方起点)
数学角度 = 90° - 0° = 90°
弧度 = 90° x π/180° = π/2 ≈ 1.5708

第三步：极坐标投影

极坐标投影公式（基于长安中心）：
X = X₀ + r x cos(θ)
Y = Y₀ + r x sin(θ)

参数说明：
X₀, Y₀ = 长安中心坐标 (109.3°, 35.5°)
r = 星宿到中心的距离（归一化长度）
θ = 数学角度（弧度制）
X, Y = 最终的地图坐标

具体计算（以角宿为例）：
r = 1.0 (标准化距离)
θ = π/2 (90°弧度)
X = 109.3 + 1.0 x cos(π/2) = 109.3 + 0 = 109.3
Y = 35.5 + 1.0 x sin(π/2) = 35.5 + 1 = 36.5

天人感应与占星应用

汉代统治者利用分野理论来诠释天象，进行政治决策和权力合法化。

占星应用实例

星象异变的预示意义
彗星出现于某宿： 表示该宿对应州郡将有兵乱或灾祥
新星、客星： 预示权力更替或重大政治变化
星色变化： 深红色示凶兆，白色示吉祥
汉代历史记录
汉武帝时期，司马迁根据分野理论预测了多次政治事件。汉成帝时期，河平四年心宿异变被解释为后妃干政的警示。这类记载充分说明了分野学在汉代政治中的重要作用。
权力合法化工具
皇帝利用分野理论来解释自然灾害并调整政策。例如，若某州郡对应的星宿出现异常，皇帝会赦免该地税收或更换地方官员，体现"天意"。

占星原则总结

对应关系: 天上星宿 ↔ 人间州郡
变化规律: 天象异常 → 地方异变
时间周期: 短期预测(数月内) | 长期预兆(数年)
可靠性: 后验性强 | 预测性相对弱
